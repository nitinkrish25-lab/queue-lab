What is adapted—and what is not?

PAPER 1

GPU multi-queue priority design

The paper distributes concurrent GPU priority-queue operations across multiple queue instances using GPU-specific techniques. This simulator demonstrates a simplified CPU-process lane-distribution idea, not the original MBGPQ data structure.

PAPER 2

State-aware scheduling for bursty traffic

The paper uses a Whittle-index method for network output queues. Adaptive priority here is a simpler waiting-time aging proposal; it is not a Whittle-index implementation.
